# YULIM PRIVATE OS

정적 웹사이트 형태의 아이디어 소개 페이지입니다.

## 구성
- `index.html`: 전체 페이지 (HTML/CSS/JavaScript 포함)\n- `yulim_logo.png`: YULIM 공식 로고
- 외부 라이브러리, 서버, AI API, 빌드 과정 없이 동작합니다.
- 맞춤 설계 체험의 선택 내용은 브라우저 안에서 처리되며 외부로 전송되지 않습니다.

## GitHub Pages 배포
1. GitHub에서 새 저장소를 만듭니다. 예: `yulim-private-os`
2. `index.html`을 저장소 최상위(root)에 업로드합니다.
3. 저장소 Settings → Pages → Deploy from a branch → `main` / `/ (root)` 선택 후 Save.
4. 잠시 후 `https://khlee-74.github.io/yulim-private-os/` 형태로 접속합니다.

## 로고 교체
현재는 텍스트 기반 YULIM 워드마크를 사용합니다. 공식 로고 파일을 준비하면 이미지로 교체할 수 있습니다.

## 안내
이 페이지는 사업 방향을 소개하는 기획 페이지이며, 제품별 기능·보안 수준·출시 여부를 보증하는 판매 페이지가 아닙니다.
